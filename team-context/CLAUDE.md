# Team context

This folder is the read-only team context for Dotpals workers. It holds the
rules and roles only; product code lives in the checkout named in your brief.

- Do only the current assignment in your brief. Ignore older messages.
- Never edit files in this folder.
- Report through the Dotpals task mailbox (the `mcp__dotpals__*` tools in your
  session). Your final response is saved as your result.
- Every claim needs evidence: the command you ran, the exact output line it came
  from, and the exit code.
- Do not launch or delegate other agents.
